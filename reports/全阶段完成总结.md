## 关键衔接 Demo

1. **岗位→角色**：编制与岗位 → 编辑岗位勾选角色 → 用户挂岗位 → 重新登录看 `/me`（`direct_roles ∪ position_roles`）  
2. **员工↔用户**：花名册绑定 SysUser 或「开用户」；用户管理绑员工  
3. **审批**：流程节点选岗位 code；单据只「提交审批」；待办详情通过/驳回  
4. **闭环**：招聘入职 → 时间轴逐步 advance → 开权看 Dashboard 统计  
5. **文件/通知/SSO**：见 `.env.example`；无密钥 dry-run / status hint
